# Mazen Ghazly Portfolio

هذا المشروع يتكوّن من 3 صفحات رئيسية:

- الصفحة الرئيسية: https://mazen-ghzaly.github.io/
- صفحة القرآن: https://mazen-ghzaly.github.io/quran
- صفحة البروفايل: https://mazen-ghzaly.github.io/profile

## هيكل المشروع

- `index.html` → الصفحة الرئيسية
- `quran/index.html` → صفحة القرآن
- `profile/index.html` → صفحة البروفايل
- `css/` → ملفات الـ CSS الرئيسية
- `js/` → ملفات JavaScript
- `images/` → الصور العامة
- `quran/css/` و `quran/js/` → ملفات الصفحة الخاصة بالقرآن
- `profile/css/` و `profile/js/` → ملفات البروفايل
