# ✨ Quote Engine

موقع بسيط وتفاعلي لعرض اقتباسات ملهمة ومتنوعة بطريقة عشوائية.

كل ضغطة بتجيب اقتباس جديد، عشان تقدر تكتشف أفكار وكلمات مختلفة في كل مرة.

## 🌐 Live Demo

[Open Quote Engine](https://mazen-ghzaly.github.io/quotes/)

## ✨ Features

* 🎲 اقتباس عشوائي جديد
* 💡 مجموعة متنوعة من الاقتباسات
* ⚡ واجهة بسيطة وسريعة
* 📱 متوافق مع الموبايل والكمبيوتر
* 🔄 تغيير الاقتباس بضغطة واحدة

## 🛠️ Built With

* HTML
* CSS
* JavaScript
